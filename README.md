## About This Repository

This repository contains my individual work for **Software Engineering Labs 1–7**. Each lab is organized into a separate folder containing the relevant source code, reports, UML diagrams, test cases, screenshots, outputs, and supporting documentation.

The experiments cover the software development lifecycle, from requirements engineering and architectural design to implementation, static code analysis, coverage testing, and fuzz testing.

## Lab Overview

| Lab | Experiment | Work Covered |
|---|---|---|
| **Lab 1** | Requirements Engineering and UML | Functional and non-functional requirements, use-case diagram, and use-case flows |
| **Lab 2** | Agile Backlog and Sprint Simulation | Jira epics, user stories, story points, sprint boards, burndown charts, and reflections |
| **Lab 3** | Component Modelling and Architectural Design | Architecture selection, UML component diagram, interfaces, and design justification |
| **Lab 4** | Vibe Coding | Card Predictor debugging, incremental feature implementation, Git commits, and demonstration evidence |
| **Lab 5** | Static Code Analysis | Car Rental code analysis and fixes using Pylint, Bandit, and Flake8, with before-and-after reports |
| **Lab 6** | Code and Branch Coverage | Car Insurance Premium test cases, coverage analysis, screenshots, and reports |
| **Lab 7** | Fuzz Testing | Hypothesis-based input-validation testing, parser fixes, and test results |
